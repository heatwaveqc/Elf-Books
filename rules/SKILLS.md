# 24 Elder Scrolls skill identities — Geard Lif mapping candidate

[Structured skill vocabulary](skills.json) · [Mechanical mapping backlog](../MIGRATION_BACKLOG.md).

Retain the **24 named skills** as the initial TES-specific activities without assuming D20 skill 0–100, `floor(skill/5)`, additive AC, or old Warrior/Mage/Rogue resource ECL.

| Warrior-origin labels | Mage-origin labels | Rogue-origin labels |
| --- | --- | --- |
| One-Handed | Alteration | Light Armor |
| Two-Handed | Conjuration | Dodge |
| Archery | Destruction | Sneak |
| Block | Illusion | Security |
| Heavy Armor | Mysticism | Legerdemain |
| Unarmed | Restoration | Speechcraft |
| Athletics | Alchemy | Survival |
| Smithing | Enchanting | Lore |

The columns are **Elder Scrolls content classifications**, not automatically Geard Lif's Attribute, Talent, Skill, Specialty, or Origins. Geard uses separate accuracy/potence/avoidance/resilience functional roles; determine how each skill applies to those roles before character creation.

Historical names retain their semantic mappings: Long Blade/Spear/etc. to appropriate weapon technique, Acrobatics to Athletics/Dodge, Lockpicking to Security, Armorer to Smithing, Pickpocket to Legerdemain, Medical to Survival. No hidden universal language skill or class level.

Each skill's specific contribution to a d10 pool, prerequisite rating, training and effect must be designed. The 48 historical D20 perk seeds and original 0–100 gates are preserved in [the archive](https://github.com/heatwaveqc/Elf-Books/tree/archive/d20-pre-geard-lif); the 75 original-game inspirations remain in [tes_perk_seeds.json](../design/tes_perk_seeds.json) as **unpriced, ungated content research**.
