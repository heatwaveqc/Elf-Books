# Fair solo GM protocol — Geard Lif adapter (not yet playable)

**Hard gate:** Do not run actual campaigns while [rules index](../rules/RULES_INDEX.md) reports unresolved mechanics. Archived D20 formulas are not fallbacks.

For each legitimate consequential action when playable:

1. Load the one authorized private campaign, current scene, pinned **Elf-Books commit** and **Geard upstream snapshot SHA**, and private GM state.
2. Describe only PC-perceivable situation and immediate stakes. Player declares action. If the event spans a project, define Scope and Time honestly.
3. Apply the correct Geard **Project**: Complexity, Recalcitrance, Scope, Time. **Accuracy meets or exceeds** static Avoidance/Complexity to apply; then Potence independently produces severity marks from zero/Minor/Middling/Major/Final based on effective Resilience/Recalcitrance thresholds. Project **Scope** gives slots per grade and completion via Final exhaustion. Do not invent unresolved armor threshold modifiers or critical predicates.
4. Obtain and record **actual d10 faces** for all legal Application and Effect rolls, and for independent non-spell Costs when applicable. State dice pool inputs, actual successes, Tier conversion, static target stats and outcomes; secret enemy/GM dice remain separate from player-facing narrative.
5. Award XP on genuine source-tagged d10s (**2 Attribute / 1 Talent / 5 Skill / 10 Specialty XP per success**) and per-natural-10 Skill/Specialty bootstrap when below rating five; calculate before rank-up, deduplicate event IDs, and apply graded resource marks (Injury, Fatigue, Attention, Mana, Plasticity, Spirit), Project progress, elapsed fictional Time, gear, NPC decisions, costs, practice awards and independent world clocks. If multiple weeks are summarized in one message, resolve the real intervals.
6. Append public/private event records and update current state atomically in the private store; read back confirmed save revision. If unavailable, clearly state **UNSAVED** and do not continue from imaginary persisted changes.
7. End with an actionable player choice; do not dictate the PC's action or retrofit clues and antagonists to force a plot.

Protect GM mysteries from public files, maintain chronological TES lore, and let independent actors act. See [P0 four-scene tests](../MIGRATION_BACKLOG.md).

**When play is eventually enabled:** record the *chosen Tier* of each roll and the same-Tier governing-Attribute/Skill die gates; no silent import of lower-Tier personal dice. Award raw XP with one `5^Tier` multiplier and let the player bank maxed-source XP for up-tier advancement or cascade it along Talent→Attribute→Skill→Specialty. For genuine selected passive defense or Cost resistance, credit `rating/10×5^Tier` XP only to participants, in **integer tenths**. Verify all spend/cascade and selection against the pinned campaign state. Static defensive value is **floor(total eligible dice / 2)**.

**Rounding and common magic:** floor half of **total** legal defensive dice when building static Avoidance/Cost resistance. Tier-0 passive XP rounds `rating/10` **up per actually used trait**; Tier 1+ can be fractional and stays in tenths. A Destruction cast rolls Perception+Destruction Accuracy and Intelligence+Destruction Potence (with applicable Talent/Specialty); its shared Potence successes plus fixed designed spell-parameter surcharge is graded against **static Will + applicable Talent + Destruction Skill + declared Spell Specialty + eligible cost-reducing robes**, with **Will determining Mind/Mana mark capacity**. Default countermagic is chosen Wits+Mysticism, not stacked with Dodge. Do not roll independent spell Cost dice or invent unpriced parameter surcharges or counterspell reaction timings. A one-hour Intelligence + School study roll trains a spell Specialty; rating 1 unlocks casting.

**Resource routing:** Mind/Will has slow Spirit and fast Mana, Body/Health slow Injury and fast Fatigue, Soul/Conviction slow Plasticity and fast Attention. Ensure the character's capacity, recovery cadence, and event ledger reference the correct aspect. Do not credit cost resistance to absent Talent/Specialty dice.

**Mode selection:** Name **Attribute + Skill**, adding Talent iff it governs that Skill, one applicable Specialty and relevant external bonuses. For any contest, record its mode and **one** legal defense from [attack_modes.json](../rules/attack_modes.json), including situational requirements. Cold exposure/direct freezing use Health + Survival; flying ice spear/arrow may Dodge or Block but not normally Parry. Social influence modes have named defenses. Sum equipment, enchantments, ensorcellments and temporary magic dice toward a **single external cap equal to the original personal dice**, not separate limits per source or effect.

**Social mark routing:** no mundane persuasion, rumor, intimidation or reputation effect may directly add **Plasticity** marks; those can directly mark **Attention**, change social Projects or create narrative consequences. Only a specifically **supernatural** attack may directly mark Plasticity. **Conviction is Soul soak and mark capacity**, never ordinary social Avoidance; use Insight/Temperance and suitable Skill responses. Physically imposing intimidation can use **Strength + Speechcraft** offensively. Deny an invalid mode even when its attacker rolls many successes.

**Effect routing before marking:** for every successfully applied effect or rolled Cost, record its declared resource target, then check whether the **fast target was already exhausted at the start of this incident**. If so, apply the full magnitude to that aspect's slow track (**Fatigue→Injury, Mana→Spirit, Attention→Plasticity**) using its own effective severity threshold. The effect that *causes* fast exhaustion does not double-hit slow. Never reject ordinary social damage to Plasticity when it occurred through prior Attention exhaustion; the restriction is only on *directly targeting* Plasticity. Track original target, actual destination and whether overflow occurred in the state ledger. Use separate capacity and recovery on each track.

**Persistent and compound spell protocol:** A damaging persistent area is anchored where cast; a victim may exit it. Physical single-target hazards must list a genuine removal action/condition, and magical single-target curses require new legitimate active resistance before each damaging turn. **The first success ends the curse permanently and prevents that turn's damage**; failure inflicts original Potence damage and the curse continues. Use the recorded original Potence on each tick—**do not roll new caster Potence, charge recurring Mana, or award new caster XP** per tick by default. For a combined formula, verify its creation was perk-gated; resolve each component's real Potence, target resistance and **separate** Cost incident, checking Mana→Spirit overflow between components. Weight is handled by work against Projects, not a parameter surcharge. Numeric schedule in [Spell Parameters](../design/SPELL_PARAMETERS.md) is provisional.

**Healing/Oakflesh Application:** Do not invent a third universal casting roll. A willing accessible target of healing or protection bypasses Perception + School Application, **not** the spell's Intelligence + School Potence and associated Mana Cost. Unwilling targets require a real Application check against an eligible named defense. Healing reverses Injury, grading restorative Potence against the **patient's base Health Resilience**, not protective Oakflesh or armor bonuses; use **universal Geard Lif supernatural restoration** for any legitimately named resource track: each restorative mark of grade g subtracts `(R+1)^g` Minor-mark equivalents from the target track's combined value (R = its base aspect Resilience), floors at zero, and rebuilds canonical mark grades. This undoes ordinary infliction/promotion. **Do not** substitute the natural lowest-grade-first `Track.recover_step()` procedure as an overflow fallback: natural recovery's seven steps for an isolated Health-2 Major wound are not supernatural Major healing's nine Minor equivalents. Never turn off separate Injury/Spirit/Plasticity damage by healing only the paired fast resource. Ordinary healing cannot resurrect a target whose Injury is already exhausted/dead. For Oakflesh, add cast Potence **directly** to effective Injury grade threshold as a flat equipment-equivalent protective effect; **never add Health slots, increase Health rating, or convert Potence into Dodge dice**. Stacking with armor and other buffs is pending. Summoning remains unspecified.

**Bankable perk points (Elf Books):** For each legitimate consequential actual dice event, preserve the **original d10 faces split into Attribute/Talent/Skill/Specialty and equipment**. The acting character confirms every **PERSONAL-source original 10** using exactly one independent d10; each confirmed 10 awards one bankable character perk point. On a genuine hostile attack against a real defender, the **defender** confirms each **attacker PERSONAL-source original 1** independently; each confirmed 1 awards that defender one bankable point, **even on a miss**. Never use fake defensive dice merely because Avoidance is static; do not award one original 1 to multiple bystanders. **No per-roll point cap**; confirmations do not modify the original action, generate XP or bootstrap, nor trigger more confirmations. Never include equipment dice in either character-perk confirmation set; proposed equipment deed enchantments from gear 10s remain unimplemented. Log all confirmation faces, eligible source counts, event ID and recipient; ensure event ID is credited only once. Perk buying: named Attribute + (starting Talent only if governing Skill) + Skill + best one listed acceptable Specialty, actual 0–25 ratings, against the perk's 0–100 threshold; equipment cannot satisfy it. **No starting-Talent perk trees**; supernatural vampire/werewolf trees deferred. See [Perks](../rules/PERKS.md) and [perk helper](../scripts/perks.py).

**Combat perk pilots (effect-only, not purchasable until gated):** [Power Bash](../design/COMBAT_PERK_PILOTS.md) permits up to die-equivalent Strength bonus Damage dice on a muscle-powered bash and adds **2 extra attempted-attack Fatigue hazard dice for each bonus die**; rolling its Cost is mandatory even on a miss. Record extra dice as `perk` source, **not** character stat source or gear. **Deflect Arrows** is the specific exception allowing a weapon Parry against arrows with the existing **one defensive action + normal Parry Cost**, and still requires an actually parry-capable weapon. **Dual Flurry** grants two independent full strike+Cost incidents per one attack action while wielding two ready melee weapons, applying the first incident's fatigue/penalties before the second. Confirm character perk-point 10s/1s on legitimately sourced personal dice from each actual strike separately; never count Power Bash technique dice as natural stat dice. Do not invent the still-open perk purchase thresholds or Arcane Blacksmith enchanting mechanics.
