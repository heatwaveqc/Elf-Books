# Start an Elf-Books solo campaign

> **Not yet playable.** These onboarding instructions describe the intended runtime. The GM must not invent finalized advancement/combat/magic rules while the mechanics are pending.

## Future player prompt

> I want to play an independent, classless, Elder Scrolls-inspired d20 game using https://github.com/heatwaveqc/Elf-Books. Read START_HERE.md and AGENTS.md; check whether the required rules have been finalized. If not, tell me what is missing instead of pretending. When the system is ready, ask me about era/place, character concept, progression method and desired campaign style. Develop and save a private campaign with a real antagonist and a prepared opening before play. Never show me GM-only plans.

Resume later with: **Resume Elf-Books campaign `<campaign-id>` from my private campaign storage.** The campaign ID and authorized store must be provided; don't guess or search other players' saves.

## Player setup — conversation, not a form
1. Historical era and initial region; how strict should established lore be?
2. Character concept, origin and actual beginning skill profile. An archetype is optional, never required.
3. Preferred advancement model and pacing (pending design approval). The decision is stored per campaign.
4. Tone, challenge/lethality, travel/combat/social emphasis, content boundaries and supporting companions.
5. Public campaign premise and character sheet approved, then private GM pre-session work, validated save and actionable first scene.

If repo is read-only or the save store isn't writable, call the session explicitly temporary. Do not promise secrets are truly hidden from someone who has access to the private repository.
