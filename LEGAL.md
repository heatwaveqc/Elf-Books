# Content provenance and licensing

Elf-Books is an **unofficial, noncommercial Elder Scrolls-inspired fan project**, unaffiliated with Bethesda or ZeniMax. Unlicensed setting trademarks and protected story/game assets are not placed under another game's license merely because the project is free.

## Mechanical upstream

The base engine is **Geard Lif / Raven's Heart**, developed in [heatwaveqc/geard-lif](https://github.com/heatwaveqc/geard-lif). Elf-Books includes a pinned local copy of **four explicitly player-audience rule pages**, selected from the owner's related source repository with authorization under this project's development request. Source commit and paths appear in [engine/geard-lif/UPSTREAM.json](engine/geard-lif/UPSTREAM.json).

The upstream repo is currently private, and no blanket reuse license is declared here. This import **does not license** third parties to copy Geard Lif's proprietary material beyond any separate authorization from its owner. AI-only and GM-only upstream material is not republished in Elf-Books.

## Deprecated D20 source

Earlier Elf-Books experiments referenced SRD 5.2.1 / D&D under CC BY 4.0. Their source attribution and archive files are preserved on [archive/d20-pre-geard-lif](https://github.com/heatwaveqc/Elf-Books/tree/archive/d20-pre-geard-lif), **not as rules active on main**. The current engine is not a D20/SRD derivative merely because the project Git history retains that experiment.

## Elder Scrolls

No imported game art, data dumps, licensed maps, quest-dialogue collections or verbatim fan-wiki prose. Keep short original summaries, documented historical uncertainty and source links. Any future public release still requires a legal/provenance review.
